🧮 Basic Calculator

📌 Project Description

The Basic Calculator is a beginner-friendly web development project built using HTML, CSS, and JavaScript. It provides a simple and interactive interface for performing basic mathematical calculations.

The calculator supports arithmetic operations such as addition, subtraction, multiplication, and division. It uses CSS Grid to organize the buttons and JavaScript to handle user interactions and calculate results.

✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal number calculations
- Clear All (AC) functionality
- Delete (DEL) functionality
- Error handling for invalid calculations
- Interactive buttons with hover effects
- Responsive user interface
- Modern design with a gradient background

🛠️ Technologies Used

- HTML5 – Structures the calculator interface.
- CSS3 – Styles the calculator and buttons.
- JavaScript – Handles button clicks and mathematical operations.
- CSS Grid – Arranges the calculator buttons in a grid layout.

🚀 Getting Started

Follow these steps to run the project on your computer.

Prerequisites

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- Visual Studio Code or another code editor.
- Live Server extension for Visual Studio Code (optional).

Installation

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Replace "YOUR_GITHUB_REPOSITORY_URL" with your actual GitHub repository URL.

Step 2: Navigate to the project folder

cd Basic-Calculator

Step 3: Open the project in Visual Studio Code

code .

Step 4: Run the calculator

Open "index.html" in your browser, or right-click the file in Visual Studio Code and select Open with Live Server.

🧑‍💻 How to Use

1. Open the calculator in your web browser.
2. Click the number buttons to enter a mathematical expression.
3. Select an arithmetic operator such as "+", "-", "×", or "÷".
4. Enter the next number.
5. Click "=" to calculate the result.
6. Click "AC" to clear the entire expression.
7. Click "DEL" to delete the last entered character.
